### Notes
  - Set your texture names under Object Properties for just one mesh object, and make sure it is selected as the active object before export
  - Set a material name like `m_body` and make sure it has an Image Texture as its Base Color e.g: `c001_tex_a_re_tex.png`

#
📦 Recommended Model Import Settings
- ✔ Flip UV V-Axis
- ✔ Reverse Triangle Winding Order
- Import LODs for Each Mesh (Only if you want all LODs)

📤 Recommended Model Export Settings
- ✔ Flip UV V-Axis
- ✔ Reverse Triangle Winding Order
